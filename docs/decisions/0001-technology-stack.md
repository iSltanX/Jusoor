# 0001 — التقنية المعتمدة

**الحالة:** معتمد · **التاريخ:** 19 يوليو 2026

## القرار

| البند | الاختيار |
|---|---|
| إطار الإضافة | WXT 0.20 |
| الواجهة | React 19 |
| اللغة | TypeScript 5.9 بوضع صارم |
| صيغة الإضافة | Manifest V3 |
| التنسيق | CSS عادي قائم على Tokens المعتمدة |
| مدير الحزم | pnpm 11 |
| الاختبارات | Vitest |
| الفحص الساكن | ESLint + typescript-eslint |

## الأسباب

- **WXT** مبني على Vite، فيبقى قريبًا من أدوات حزمة الهوية. يولّد الـmanifest من إعداد
  واحد، ومخرجاته إضافة قياسية بلا قفل، ويدعم أهدافًا متعددة من مصدر واحد فيبقى Firefox ممكنًا.
- **React** لأن أصول الهوية القابلة لإعادة الاستخدام (`icons.tsx` وأوليّات `ui.tsx`)
  مكتوبة به؛ أي بديل يعني إعادة كتابة الهوية.
- **TypeScript صارم** لأن نموذج جُسور قائم على تصنيفات متعامدة وحالات محدودة تعيش على
  الأنواع المميزة. مفعّل معه `noUncheckedIndexedAccess` و`exactOptionalPropertyTypes`.
- **CSS عادي** ولا Tailwind: نظام الهوية معرَّف بقيم وأصناف دلالية، وإعادة التعبير عنه
  بـutilities تنشئ نظامًا موازيًا يحظره دستور الهوية §2.

## البدائل المرفوضة

| البديل | السبب |
|---|---|
| Plasmo | تجريد أثقل وسلوك ضمني أكثر بلا مقابل لمنتج محلي |
| CRXJS | دعم أضعف لتعدد المتصفحات وصيانة متقطعة |
| Vite خام متعدد المداخل | ممكن، لكنه يعني كتابة توليد الـmanifest وHMR لعامل الخدمة يدويًا. يبقى خطة الطوارئ |
| Tailwind | نظام موازٍ للقيم المعتمدة |
| مكتبة مكونات منسَّقة جاهزة | تستبدل الهوية بدل استهلاكها |
| TypeScript 7 | غير مدعوم من typescript-eslint (`>=4.8.4 <6.1.0`) |

## ما لم يُضف

لم تُضف مكتبة إدارة حالة ولا مكتبة تحقق من مخططات ولا مكتبة ترجمة: لا حاجة مثبتة في
نطاق التأسيس. تُراجَع عند تصميم نموذج البيانات. التبعية الوحيدة المضافة لغرض اختباري
هي `fake-indexeddb`، لتشغيل اختبار فتح القاعدة في بيئة node.

سكربتات تثبيت التبعيات معطّلة كلها (`onlyBuiltDependencies: []` في `pnpm-workspace.yaml`).
