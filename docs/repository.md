## صور المستودع

| الموضع | الأصل المعتمد | طريقة التطبيق |

| لقطات الشاشة | `docs/screenshots/` | مضمّنة في الصفحتين؛ ليست أصول هوية |

### لماذا `repository-cover.png` لا `readme-header.svg`

`readme-header.svg` يعرّف نصه بـ`font-family="Almarai"` و`"Cairo"` بلا تضمين الخط
داخل الملف. وGitHub يعرض SVG المستودع داخل `<img>`، فلا يُحلّ الخط ويسقط النص إلى
بديل النظام — والقياس الفعلي في Chrome عند 1280×320 أظهر أن «جُسور» والسطر العربي
يتجاوزان الحافة اليمنى ويُقصّان، لأن `text-anchor="end"` مع `direction="rtl"`
يُقاس على مقاييس خط مختلف. أي أن الرأس كان **معطوبًا بصريًا** على صفحة المستودع.

`repository-cover.png` أصل معتمد في دستور الهوية §14 تحت فئة «المستودع والمنتج»
نفسها، ونصه مُنقَّط بالخطوط الصحيحة أصلًا فلا يعتمد على بيئة العرض. التبديل استعمال
أصل معتمد آخر لغرضه المعلن، **لا تعديل على `identity/`** ولا إنشاء أصل جديد.

الملاحظة مسجَّلة كذلك في «فجوات مرصودة في الحزمة» في
[identity-source.md](identity-source.md) — معالجتها داخل الحزمة تحتاج قرار هوية.

## صفحتا المستودع

| الملف | اللغة | الدور |
|---|---|---|
| `README.md` | العربية | الصفحة الأساسية للمشروع — ما يعرضه GitHub افتراضيًا |
| `README.en.md` | الإنجليزية | نسخة كاملة مطابقة في المحتوى، لا ملخصًا |

الصفحتان متكافئتان: كل قسم في إحداهما له مقابله في الأخرى، ومبدّل اللغة في أعلى كلٍّ
منهما وفي تذييلها. لا تُحدَّث واحدة دون الأخرى.

اللقطات في `docs/screenshots/` مأخوذة من الحزمة المبنية فعلًا (لا نماذج تصميمية)،
بعرض اللوحة المرجعي 380px وبكثافة ‎2x‎، عربية وإنجليزية وفاتحة وداكنة.

## قرار الرؤية (Visibility): من خاص إلى عام

| | |
|---|---|
| **القرار القديم** | مستودع المصدر **خاص (Private)** — من الإنشاء وحتى انتهاء الصقل النهائي لـV1.1.0 والتحقق اليدوي منه. |
| **القرار الجديد** | مستودع المصدر **عام (Public)**. |
| **السبب** | توحيد الكود والإصدارات في مكان واحد، وزيادة الشفافية والثقة، وتسهيل المراجعة والمساهمة. |
| **الأثر** | الكود والتاريخ الكامل (commit واحد حتى الآن) والـIssues والـReleases (بما فيها v1.1.0 وحزمتا Chrome وEdge) تصبح متاحة للعامة دون تسجيل دخول. |

سبق هذا القرار فحص شامل للأسرار (الشجرة وتاريخ Git الكامل عبر كائنات Git
مباشرة) ومراجعة قانونية (اعتماد ترخيص MIT، وإخراج
`Jusoor-Identity-System-v2.zip` من التتبع العلني لعدم وضوح حق نشره كاملًا للعامة
— انظر [identity-source.md](identity-source.md)).

## إعدادات مطبَّقة فعليًا

- الرؤية: **Public** (بعد أن كانت Private).
- الفرع الافتراضي: `main`.
- Issues: مفعّلة (افتراضي GitHub عند الإنشاء؛ لم يُتخذ قرار صريح بإيقافها).
- Discussions وWiki: غير مفعّلتين.
- `about` الجانبي: الوصف أعلاه.
